# 🚀 Vooler — Interactive 3D Model

An interactive 3D visualization of the **Vooler** device, designed to demonstrate its structure, components, dimensions, and different operating states through a web-based interface.

## 🌐 Live Demo

🔗 **[View Vooler 3D Model](YOUR-VERCEL-LINK-HERE)**

> The project is deployed as a lightweight static web application and can be accessed directly from a browser.

---

## 📌 About Vooler

**Vooler** is a smart cooling/storage device concept designed to provide controlled storage conditions while allowing users to visualize and monitor the system.

This project provides a **3D interactive representation** of the Vooler device, making it easier to understand its physical structure and internal components.

---

## ✨ Features

- 🧊 Interactive 3D Vooler model
- 🔄 Rotate and explore the model
- 🔍 Zoom and pan controls
- 👁️ Multiple camera views:
  - Front
  - Rear
  - Left
  - Right
  - Top
  - Bottom
- ⚙️ Different operating states
- 🧩 Component visualization
- 📏 Dimension display
- 🖥️ Browser-based interface
- 📦 Self-contained HTML application
- 🚀 Can be deployed as a static website

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**
- **Three.js**
- **WebGL**

The application contains the required JavaScript and 3D rendering code directly inside the HTML file, allowing the project to run without a traditional backend.
